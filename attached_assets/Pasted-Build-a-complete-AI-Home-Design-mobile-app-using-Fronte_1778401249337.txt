- Frontend: React Native (Expo)
- Backend: Node.js + Express
- Database: MongoDB + Mongoose

─────────────────────────────────────
EXPRESS ROUTES:
─────────────────────────────────────

AUTH ROUTES (/api/auth):
POST /register → create user, return JWT
POST /login → validate credentials, return JWT
GET  /me → get current user (protected)
PUT  /update-profile → update name, avatar
POST /forgot-password → send reset email

DESIGN ROUTES (/api/designs) [all protected]:
GET    /          → get all user designs (paginated)
POST   /          → save new design
GET    /:id       → get single design
PUT    /:id       → update design
DELETE /:id       → delete design
POST   /:id/favorite → toggle favorite
GET    /favorites → get all favorited designs
GET    /history   → get recent 20 designs

AI ROUTES (/api/ai) [protected]:
POST /generate → call Claude API, deduct credit, save response
POST /tip       → get daily design tip
POST /analyze   → analyze uploaded room image
GET  /credits   → get remaining AI credits

PROJECT ROUTES (/api/projects) [protected]:
GET    /     → get all user projects
POST   /     → create new project
PUT    /:id  → update project
DELETE /:id  → delete project
POST   /:id/add-design → add design to project

─────────────────────────────────────
AI CONTROLLER (aiController.js):
─────────────────────────────────────

generateDesign(req, res):
1. Check user has AI credits (return 403 if 0)
2. Build prompt based on featureType + selectedStyle + selectedRoom
3. Call Claude API:

const response = await fetch("https://api.anthropic.com/v1/messages", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-api-key": process.env.ANTHROPIC_API_KEY,
    "anthropic-version": "2023-06-01"
  },
  body: JSON.stringify({
    model: "claude-sonnet-4-20250514",
    max_tokens: 1000,
    system: "You are an expert interior designer AI. Give specific, actionable design advice in bullet points under 200 words.",
    messages: [{ role: "user", content: req.body.prompt }]
  })
})

4. Deduct 1 credit from user: User.findByIdAndUpdate(userId, { $inc: { aiCredits: -1 }})
5. Save design to DB with aiResponse
6. Return response to client

─────────────────────────────────────

- Connect MongoDB with mongoose
- CORS, helmet, rate limiting (100 req/15min)
- Mount all routes
- Error handling middleware
- Listen on PORT 5000

SECURITY & EXTRAS:
═══════════════════════════════════════

- JWT expires in 7 days, refresh token in 30 days
- Passwords min 8 chars, hashed with bcrypt (saltRounds: 12)
- Rate limit AI endpoint: 20 requests/hour per user
- Validate all inputs with express-validator
- Free plan: 10 AI credits/day (reset midnight)
- Pro plan: unlimited credits
- All API errors return { success: false, message: "..." }
- All success returns { success: true, data: {...} }
